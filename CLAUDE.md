# Writing Style

When writing documents for this user (PRDs, specs, summaries, any prose
deliverable), write in flowing paragraphs. Avoid stacking heavy nested
bullet lists and dash-separated fragments as the default structure — that
reads as AI-generated. Use a bullet or table only when the content is
genuinely list-like (a set of options, a data table, an event/property
spec) — not as a default formatting habit for every paragraph.
